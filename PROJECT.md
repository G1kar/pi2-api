---

## Этапы канбан-доски

| Этап | Описание |
|------|----------|
| **Backlog** | Идеи и требования, ещё не принятые в работу |
| **To Do** | Задачи приняты в спринт, ожидают исполнителя |
| **In Progress** | Задача в работе |
| **Review** | Код/документ готов, ожидает проверки |

## Сводка по этапам

- **Backlog:** при появлении новых идей (например, дополнительные метрики, доработка UI) задачи сначала попадают сюда.  
- **To Do:** задачи из таблиц выше, помеченные как To Do, либо перенесённые из Backlog.  
- **In Progress:** задача берётся в работу — перенос карточки в этот столбец.  
- **Review:** после завершения разработки/документации — перенос в Review до проверки.  
- **Done:** после принятия результата — перенос в Done (как отражено для уже реализованных пунктов).

При необходимости этапы можно уточнять (например, добавить «Testing» или «Deploy»); распределение по ролям можно менять по согласованию команды.
